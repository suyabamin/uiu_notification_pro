
## Naming Conventions

| Item | Convention | Example |
|------|-----------|---------|
| Files | `kebab-case.ts` | `alarm-manager.ts` |
| Components | `PascalCase.tsx` | `UpdateItem.tsx` |
| Types / Interfaces | `PascalCase` | `PortalSnapshot` |
| Constants | `SCREAMING_SNAKE_CASE` | `DEFAULT_INTERVAL_MIN` |
| Functions | `camelCase` | `fetchSnapshot()` |
| CSS classes | Tailwind utilities | `bg-brand-500` |

## Storage Key Naming

All keys are namespaced with `portal-monitor:` prefix.

| Key | Type |
|-----|------|
| `portal-monitor:settings` | `Settings` |
| `portal-monitor:elms-token` | `string` |
| `portal-monitor:snapshots:ucam` | `PortalSnapshot` |
| `portal-monitor:snapshots:elms` | `PortalSnapshot` |
| `portal-monitor:updates` | `Update[]` |
| `portal-monitor:notified-ids` | `string[]` (session) |
| `portal-monitor:last-check` | `{ ucam: number; elms: number }` |

## Message Contract Names

All uppercase snake:

- `CHECK_NOW`
- `GET_STATE`
- `SAVE_SETTINGS`
- `SAVE_ELMS_TOKEN`
- `REVOKE_ELMS_TOKEN`
- `CLEAR_HISTORY`
- `MARK_READ`
- `MARK_ALL_READ`
- `LOGIN_STATE_CHANGED` (content → background)
